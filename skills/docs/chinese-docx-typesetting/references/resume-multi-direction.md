# 中文简历：板块顺序、多方向定位与雷点检查

## 板块顺序（现代中文简历，单页）

1. **姓名 + 定位句**（定位句与姓名分两行，靠左）
2. 联系方式一行：`男 · 出生年月 · 电话 xxx · 邮箱 xxx`
3. **个人概述** 3–4 行：行业年限 + 三方视角/背景跨度 + 最硬的两个数字 + 擅长的方法论
4. **核心能力** 4–6 条：每条 `能力名：具体手段`，写的是可被 ATS 抓取的关键词，不是形容词
5. **项目经历**（技术/AI 方向放在工作经历之前；商业方向通常省略或并入工作经历）
6. **工作经历** 倒序：每段 1–2 条 bullet，强动词开头，量化结果加粗并前置
7. **教育背景** 倒序，`学校 | 学位 · 专业` + 右侧时间
8. **资质与技能** 2–3 行

排版参考：A4、页边距 15mm、正文 10.5pt、微软雅黑、强调色深藏青 #1F3A5F、章节标题带下分隔线。**中文简历默认目标是 1 页**；超过 1 页只在内容确实无法删减时接受。

## 定位句写法

模式：`<角色名>｜<工具/方法A> × <方法B> × <方法C>`

- 角色名选对方岗位的语言（对方招「特殊资产处置」就不要写「信托经理」）。
- 后面三个用 × 连接，是这条简历的技术栈宣言，也是关键词密度最高的一行。

## 一份经历，多个方向的定位表

同一段经历在不同方向下的讲法（左边是方向，右边是主线与优先前置的事实）：

| 方向 | 定位主线 | 优先前置的事实 |
|---|---|---|
| 财富管理 / 家办 | 传承架构 + 跨境税务合规 | 受托规模、促成保费、CRS/美国税、渠道与团队管理 |
| 不良资产 / 特殊资产 | 重组涉税 + 资产隔离工具 | 架构重整、资产划转涉税、资产隔离与风险切割、资产类型 |
| 投融资 / 资本运作 | 顶层股权架构 + 交易涉税 | 上市前重组、股权转让、股权激励、股权类信托 |
| AI / 技术落地 | 懂业务的落地者 | 已上线的具体系统与工作流，不是「熟悉大模型」 |

**AI / 技术方向的关键做法：把他本机真实存在的产出逐个点名**（自有仓库与技能包、定时任务/生产流水线、自研的服务与数据接入、打包分发的工具），写成项目经历。这类条目别人抄不走，是这份简历唯一无法被同质化竞争者复制的部分。写「了解 LLM/Agent」是零分，写「某申报自动化链路 + 一键安装的分发技能包」是满分。

## 事实不够的方向怎么处理

某些方向用户自述「做过」，但简历里没有任何可支撑的项目、数字或角色。**不要替他把这段补完。** 出一版以能力条目为主、内容偏薄但每句都可辩护的稿子，然后要这五条事实（按方向提问，一次问完）：

1. 具体项目：对象类型（股权 / 不动产 / 债权 / 基金）、规模区间
2. 他在项目里的角色（主导 / 核心成员 / 支持）
3. 有没有做过尽调或估值，什么口径
4. 有没有与外部专业机构（律所、评估、AMC、管理人）协作，在哪个环节
5. 有没有做过税负测算 / 方案论证类的交付物

### 提问要分层，不要让他重讲一遍

用户开口讲「我做过什么」之后，他给的已经是定性（在四大做过收购重组、在信托做过服务信托、接触过 Pre-IPO）。**再问「你具体做了啥」是浪费一轮** —— 真正缺的只有四样，按这个顺序一次问完，一条一句就够：

- **角色**：主导 / 核心 / 支持 / 撮合（决定用哪个动词）
- **量级**：千万 / 亿 / 十亿（问区间，不要逼他给精确值）
- **对手方**：五大 AMC 还是地方 AMC、哪个交易所或哪一轮、哪类机构
- **结构**：钱是谁的 —— 客户自有 / 平台自有 / 走信托计划还是私募资管

**用公开坐标帮他回忆。** 问「你是哪一轮进的」几乎答不上来；给出「某项目 2025 年 7 月那轮估值 120 亿、某日上市」这样的锚点，他能立刻定位到自己的轮次与成本区间。

**不要干等问答。** 用户说「先问答一下」时，先用他已经给的事实把那几版垫厚、跑出来发过去，问题清单附在后面 —— 他要的是看到进度，不是填完问卷才动笔。（垫厚通常就是把定性事实写进定位句、概述、核心能力和对应那一段的 bullet，不动数字。）

### 提问前先自己查一遍

他抛回来的术语，先核实再写：监管文件里的正式名称、该机构公开层面是否真有这条业务线、行业规模量级。核完的结论要回给他（“你记的名字官方叫……，你原东家确实设了这个部门”），顺手把正式名 + 俗称一起写进简历。这一轮查证顺便让你能问出内行问题，比泛泛问“展开讲讲”有效得多。

## 投递前的一致性检查（必须主动做，不要静默「修好」）

逐项核对并向用户报告，让他自己拍板：

- **学历时间线重叠**：两段学历期间重合（交换、转学、跨校项目都会造成），HR 会当成硬伤。确认口径后写清楚，别让读者自己猜。
- **任职时间与机构风险事件重合**：离职时间点若与老东家出事/被接管的时点吻合，面试必被追问。提醒他先想好口径（业务原因 / 个人发展），不要到场上现编。
- 有重叠或空档的任职期间、学历与任职时间冲突。
- 数字口径：简历里的规模是公司口径还是个人/团队口径，写清楚限定词（「累计受托规模」而非「管理规模」）。
- **投资类条目的动词与合规**：写「为客户获取份额」还是「主导投资」，取决于资金结构（客户自有 / 平台自有 / 信托计划 / 私募或券商资管）与他实际承担的角色（决策 / 获取 / 撮合）。结构没确认前用最保守的那个动词。
- **已上市标的不要往收益上引**：行情回撤是常态，只陈述「取得份额 + 已上市」这两个可核验事实。写收益率会让面试变成业绩追问，而这类业绩他通常拿不出可披露的凭证。
